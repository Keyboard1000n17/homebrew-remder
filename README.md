# Keyboard1000n17 Remder

## How do I install these formulae?

`brew install keyboard1000n17/remder/<formula>`

Or `brew tap keyboard1000n17/remder` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "keyboard1000n17/remder"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
